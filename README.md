# Abuja Apartment Rent Predictor

My first machine learning project. I used 400 made-up Abuja apartments to
(1) predict the yearly rent and (2) label apartments as Expensive or Affordable.

## What is in this repository
- `PROJECT_ABUJA_RENT_PREDICTOR_student(2)`: my notebook with all the code, charts and answers
- `abuja_apartments_400.csv`: the dataset

## What I did
- Explored the data and drew charts
- Trained a Linear Regression model to predict rent (MAE: ₦171685.3166188797, R²: 0.8972706081668567)
- Trained a Decision Tree to classify apartments (accuracy: 78%)
- Compared different tree depths to understand overfitting

## What I learned (in my own words)
- How models can be used to make predictions
- Multiple features in a Linear regression can improve its accuracy
- Adding too much max depth to a Decision Tree model can be harmful to the model's ability to predict.
